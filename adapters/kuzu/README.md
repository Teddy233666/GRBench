# Kuzu Adapter

The adapter contains 96 static main Cypher files. Shortest Path and Update
Cypher are generated by their runners. Use repository-relative `.local/`
storage and follow `docs/systems/kuzu.md`.

All three runners default to one warmup and three measured executions. They
publish every metric from the measured run with median elapsed time. Existing
single-run CSV files have an incompatible schema; write formal runs to a new
path or pass `--overwrite`.
