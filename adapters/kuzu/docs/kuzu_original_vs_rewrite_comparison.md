# Kuzu Original SQL vs Rewritten Query Comparison

Date: 2026-07-06

## Scope

- Original SQL root: `benchmark/queries/canonical`
- Kuzu Cypher root: `adapters/kuzu/queries`
- Main query pairs compared: 96 original SQL files vs 96 current Kuzu Cypher files.
- `Pure_Join_Queries` is represented by `benchmark/manifests/pure_join_aliases.csv`; duplicate Cypher files are not published.
- `Shortest_Path_Queries` and `update/Update` are generated by Kuzu runner scripts, so their comparison is summarized by runner mapping and source snippets rather than static `.cypher` files.

## Schema Mapping Notes

- Original `Authors_Paper(authorid, paperid)` graph patterns are represented in Kuzu through `Papers_to_Authors(FROM Papers TO Authors_Gender)`. This preserves the paper-author pair relation for aggregate results, but it collapses the original reverse edge label/direction into one Kuzu relationship.
- Link tables such as `Link_NSF`, `Link_NIH`, `Link_ClinicalTrials`, and `link_newsfeed` are represented as node tables in Kuzu when the loaded schema stores their attributes directly on records.
- The recently fixed Update `3b.sql` now loads both `grbench_update1_papers_to_authors` and the update3 author-paper delta converted to Kuzu `Papers_to_Authors` endpoint order.

## Main Query Pairs

### `High_Join_Relational_Graph_Hybrid_Queries/High-Join Multi-Subgraph Multi-Hop/1a.sql`

- Original: `benchmark/queries/canonical/High_Join_Relational_Graph_Hybrid_Queries/High-Join Multi-Subgraph Multi-Hop/1a.sql`
- Kuzu rewrite: `adapters/kuzu/queries/High_Join_Relational_Graph_Hybrid_Queries/High-Join Multi-Subgraph Multi-Hop/1a.cypher`

Original SQL:

```sql
SELECT
    MIN(g_ref.paperid) AS minPaper,
    MIN(g_ap.authorid) AS minAuthor,
    MIN(g_cf.paperid) AS minAff,
    MIN(s.sourceid) AS minSource,
    MIN(ln.laureate_id) AS minNobel,
    MIN(ad.authorid) AS minPatent
FROM
GRAPH_TABLE(
    sciscinet_graph
    MATCH (p IS Papers)-[r1 IS PaperReferences]->(p1 IS Papers)-[r2 IS PaperReferences]->(p2 IS Papers)-[r3 IS PaperReferences]->(ref IS Papers)
    WHERE p.paperid='W2122344208'
      AND ref.citation_count<150
    COLUMNS (
        p.paperid  AS paperid,
        ref.paperid AS ref_paperid,
        ref.citation_count AS citation_count
    )
) g_ref
LEFT JOIN GRAPH_TABLE(
    sciscinet_graph
    MATCH (a IS Authors_Gender)-[ap IS Authors_Paper]->(p IS Papers)
    WHERE a.h_index>10
    COLUMNS (
        a.authorid     AS authorid,
        p.paperid      AS paperid
    )
) g_ap
ON g_ap.paperid = g_ref.paperid

LEFT JOIN GRAPH_TABLE(
    sciscinet_graph
    MATCH (p IS Papers)-[cf IS contributed_from]->(inst IS Affiliations)
    WHERE inst.productivity>1000
    COLUMNS(
        p.paperid          AS paperid,
        inst.institutionid AS institutionid
    )
) g_cf
ON g_ref.ref_paperid = g_cf.paperid
LEFT JOIN papersources ps
  ON g_ref.ref_paperid = ps.paperid
LEFT JOIN sources s
  ON ps.sourceid = s.sourceid
LEFT JOIN link_nobellaureates ln
  ON g_ref.paperid  = ln.paperid
LEFT JOIN author_details ad
  ON g_ap.authorid = ad.authorid;
```

Current Kuzu Cypher:

```cypher
MATCH (p:Papers)
MATCH (p)-[r1:PaperReferences]->(p1:Papers)
MATCH (p1)-[r2:PaperReferences]->(p2:Papers)
MATCH (p2)-[r3:PaperReferences]->(ref:Papers)
WHERE p.paperid = 'W2122344208' AND ref.citation_count < 150
OPTIONAL MATCH (p)-[ap:Papers_to_Authors]->(a:Authors_Gender) WHERE a.h_index > 10
OPTIONAL MATCH (ref)-[cf:contributed_from]->(inst:Affiliations) WHERE CAST(inst.productivity AS DOUBLE) > 1000
OPTIONAL MATCH (ref)-[ps:papersources]->(s:Sources)
OPTIONAL MATCH (ln:link_nobellaureates) WHERE ln.paperid = p.paperid
OPTIONAL MATCH (ad:AuthorDetails) WHERE ad.authorid = a.authorid
RETURN MIN(p.paperid) AS minPaper, MIN(CASE WHEN a IS NULL THEN NULL ELSE a.authorid END) AS minAuthor, MIN(CASE WHEN cf IS NULL THEN NULL ELSE ref.paperid END) AS minAff, MIN(CASE WHEN s IS NULL THEN NULL ELSE s.sourceid END) AS minSource, MIN(CASE WHEN ln IS NULL THEN NULL ELSE ln.laureate_id END) AS minNobel, MIN(CASE WHEN ad IS NULL THEN NULL ELSE ad.authorid END) AS minPatent;
```

## Shortest Path Generated Mapping

- Original SQL directory: `benchmark/queries/canonical/Shortest_Path_Queries`
- Kuzu runner: `adapters/kuzu/run_shortest.py`
- Kuzu does not execute SQL/PGQ `ANY SHORTEST` directly. The runner expands each query into exact-depth Cypher steps and aggregates endpoint `MIN` values.
- `{1,}` and `{,}` are bounded by `--max-unbounded-depth` in the runner; default is `8`.

| Files | Original path length | Kuzu generated steps | Predicate family |
|---|---:|---|---|
| `1a.sql`-`1c.sql` | `{1,}` | depths `1..max_unbounded_depth` over `affl_assoc_affl` | productivity/institution filters |
| `2a.sql`-`2c.sql` | `{1,3}` | depths `1..3` over `affl_assoc_affl` | productivity/institution filters |
| `3a.sql`-`3c.sql` | `{1,4}` plus left join | depths `1..4`, then optional `contributed_from` aggregation | productivity/institution filters |
| `4a.sql`-`4c.sql` | `{,}` | depths `0..max_unbounded_depth` over `affl_assoc_affl` | productivity/institution filters |
| `5a.sql`-`5c.sql` | `{,1}` | depths `0..1` over `PaperReferences` | citation thresholds |

def affiliation_min_step(depth: int, suffix: str) -> str:
    predicates = {
        "a": "CAST(inst_for.productivity AS DOUBLE) > 8000",
        "b": "CAST(inst_for.productivity AS DOUBLE) > 48000",
        "c": "inst_for.institutionid = 'I4210088668'",
    }
    if depth == 0:
        return f"""
MATCH (inst_for:Affiliations)
WHERE inst_for.institutionid = 'I4210136388'
  AND {predicates[suffix]}
RETURN count(inst_for.institutionid) AS matched_count,
       min(inst_for.institutionid) AS min_institutionid;
""".strip()
    return f"""
MATCH p = (inst_cn:Affiliations)-{rel_pattern("affl_assoc_affl", depth)}->(inst_for:Affiliations)
WHERE inst_cn.institutionid = 'I4210136388'
  AND {predicates[suffix]}
RETURN count(inst_for.institutionid) AS matched_count,
       min(inst_for.institutionid) AS min_institutionid;
""".strip()


def contributed_from_join_step(depth: int, suffix: str) -> str:
    predicates = {
        "a": "CAST(inst_for.productivity AS DOUBLE) > 8000",
        "b": "CAST(inst_for.productivity AS DOUBLE) > 48000",
        "c": "inst_for.institutionid = 'I4210088668'",
    }
    return f"""
MATCH p = (inst_cn:Affiliations)-{rel_pattern("affl_assoc_affl", depth)}->(inst_for:Affiliations)
WHERE inst_cn.institutionid = 'I4210136388'
  AND {predicates[suffix]}
WITH DISTINCT inst_for.institutionid AS institutionid
OPTIONAL MATCH (:Papers)-[:contributed_from]->(i:Affiliations)
WHERE i.institutionid = institutionid
RETURN count(institutionid) AS matched_count,
       min(i.institutionid) AS min_joined_institutionid;
""".strip()


def paper_reference_step(depth: int, suffix: str) -> str:
    thresholds = {"a": 150, "b": 80, "c": 5}
    if depth == 0:
        return f"""
MATCH (paper:Papers)
WHERE paper.paperid = 'W4211259235'
  AND paper.citation_count < {thresholds[suffix]}
RETURN count(paper.paperid) AS matched_count,
       min(paper.paperid) AS min_ref_paperid;
""".strip()
    return f"""
MATCH p = (paper:Papers)-[:PaperReferences]->(ref:Papers)
WHERE paper.paperid = 'W4211259235'
  AND ref.citation_count < {thresholds[suffix]}
RETURN count(ref.paperid) AS matched_count,
       min(ref.paperid) AS min_ref_paperid;
""".strip()
