# Provenance and Licensing

## Repository Material

The publication tree combines material from the source aliases recorded in
`migration-map.md`: the legacy core GRBench tree, the Kuzu adapter tree, and the
OrientDB adapter tree. The public Apache-2.0 grant is valid only for material
whose copyright holders have authorized that grant. Before the first public
push, the maintainer must retain a written record confirming that the project
owns or has permission to publish the imported code, queries, documentation,
and generated result tables under `LICENSE` and `RESULTS_LICENSE`.

The clean publication repository intentionally does not import legacy Git
objects. Source aliases are provenance labels and are not local runtime paths.

## External Data and Software

No DBMS binary, model, database, or source dataset is redistributed. SciSciNet,
IMDb, MOOCCube, DBLP, and installed DBMS/package dependencies retain their own
terms. `THIRD_PARTY_NOTICES.md` and `docs/data/README.md` identify the external
sources needed by the published utilities. A source URL does not itself grant
redistribution rights; users must verify the terms of the exact artifact they
download.
